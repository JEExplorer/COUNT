# افغان بیزنس پرو | Afghan Business Pro

پروژه Flutter برای مدیریت سادهٔ دوکان، با رابط دری/فارسی و ذخیرهٔ آفلاین SQLite.

## قابلیت‌ها
- مدیریت اجناس و موجودی
- ثبت فروش و کاهش خودکار موجودی
- ثبت قرض مشتری و پرداخت‌ها
- گزارش و خروجی CSV
- داشبورد و رابط راست‌به‌چپ

## ساخت APK با GitHub
1. تمام محتویات این پوشه را در ریشهٔ مخزن GitHub آپلود کن؛ خود پوشهٔ بیرونی را به‌صورت یک زیرپوشه آپلود نکن.
2. مطمئن شو مسیر فایل ورک‌فلو این است: `.github/workflows/main.yml`.
3. در GitHub به **Actions** برو و ورک‌فلو **حساب من** را اجرا کن، یا تغییرات را روی شاخهٔ `main` ثبت کن.
4. پس از اجرای موفق، در صفحهٔ اجرا از بخش **Artifacts** فایل `Afghan-Business-Pro-APK` را دانلود کن و ZIP آن را استخراج کن تا APK را بگیری.

ورک‌فلو پوشهٔ Android را در GitHub Actions تولید می‌کند اگر در مخزن موجود نباشد. این سورس در این محیط با Flutter SDK اجرا و کامپایل نشده است؛ بنابراین موفقیت ساخت APK باید در GitHub بررسی شود و پیش از استفادهٔ تجاری باید روی دستگاه واقعی آزمایش شود.
